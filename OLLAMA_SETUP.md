# Setting up Ollama for the LLM explainer

The Layer 5 explainer uses a locally hosted LLM via [Ollama](https://ollama.com).
This document is the one-time setup guide. After completing these steps you
can re-run `scripts/08_generate_explanations.py` and explanations will be
generated by the real LLM instead of the template fallback.

## Step 1: Install Ollama for Windows

1. Go to https://ollama.com/download/windows
2. Download `OllamaSetup.exe` (~700 MB).
3. Run the installer (no admin rights required - it installs into your
   user profile at `%LOCALAPPDATA%\Programs\Ollama`).
4. After installation, Ollama starts automatically as a background service
   and listens on `http://localhost:11434`.

## Step 2: Pull the model

Open a new PowerShell window and run **one** of the following:

```powershell
# Recommended: Qwen 2.5 7B Instruct (~4.7 GB, very good Russian)
ollama pull qwen2.5:7b-instruct

# Alternative: Llama 3.1 8B Instruct (~4.9 GB)
ollama pull llama3.1:8b-instruct-q4_K_M

# Lightweight option for fast iteration: Llama 3.2 3B (~2.0 GB)
ollama pull llama3.2:3b-instruct-q4_K_M
```

The first pull downloads the model weights. Subsequent runs are cached.

## Step 3: Verify it works

```powershell
# Quick sanity check
ollama run qwen2.5:7b-instruct "Объясни одним предложением, что такое профориентация."
# Should return a brief Russian sentence.

# Confirm HTTP API is up
curl http://localhost:11434/api/tags
# Should return JSON listing the model you just pulled.
```

## Step 4: Re-run the explainer

```powershell
cd c:\Users\ik\Documents\maga\disser\system
python scripts/08_generate_explanations.py
# Backend will now resolve to "ollama" automatically.
# Each explanation takes ~10-25 seconds on RTX 4060 Laptop with Qwen 2.5 7B.
```

The script auto-detects Ollama. If it is not running, the script gracefully
falls back to the deterministic template (no error, just shorter and more
formal text).

## Performance notes for RTX 4060 Laptop (8 GB VRAM)

| Model | VRAM used | Tokens/sec (approx) | Time per explanation |
|---|---:|---:|---:|
| `llama3.2:3b-instruct` | ~2.5 GB | 80-120 | 5-8 s |
| `qwen2.5:7b-instruct` | ~4.7 GB | 35-50 | 12-20 s |
| `llama3.1:8b-instruct` | ~5.0 GB | 30-45 | 15-25 s |

Close heavy GPU consumers (games, video editors) before running for best
speed. Browsers are usually fine.

## Troubleshooting

* **`ollama` not recognized in PowerShell** - close and reopen the terminal
  after install so PATH refreshes; or call `& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" ...`.
* **`pull` fails with 403/network error** - check firewall / antivirus;
  Ollama needs HTTPS to `registry.ollama.ai`.
* **Generation is very slow on first run** - the model is being loaded into
  GPU memory. Subsequent calls in the same session are fast.
* **VRAM out-of-memory** - close GPU-heavy apps, or switch to the 3B model.
