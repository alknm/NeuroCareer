# NeuroCareer — инструкция для рецензента

Это практическая часть магистерской диссертации
**«Research and development of a hybrid career guidance system based on
neural data and psychological tests using AI»**.

Архив содержит исходный код, обученные модели, реальные пилотные данные
и автоматический запускатель — устанавливать что-либо вручную не нужно.

---

## Системные требования

| Что | Минимум |
|---|---|
| ОС | Windows 10/11, macOS 12+, или любой Linux |
| Python | **3.10 или новее** ([скачать с python.org](https://www.python.org/downloads/)) |
| Свободно на диске | 600 MB (для виртуальной среды и зависимостей) |
| Интернет | нужен **только при первом запуске** для скачивания пакетов |

При установке Python в Windows обязательно отметьте галочку
**«Add Python to PATH»** на первом экране установщика.

---

## Запуск за 3 действия

### Windows

1. Распакуйте архив в любую папку (например, `C:\NeuroCareer`).
2. Зайдите в распакованную папку, дважды кликните на **`run.cmd`**.
3. Дождитесь надписи «*You can now view your Streamlit app...*» (первый
   запуск занимает 3–5 минут — скачиваются зависимости).
   Браузер откроется автоматически на `http://localhost:8501`.

> Если Windows покажет «Защита Windows SmartScreen», нажмите
> «Подробнее» → «Выполнить в любом случае». Скрипт ничего не отправляет
> в сеть кроме скачивания пакетов с pypi.org.

### Linux / macOS

```bash
cd path/to/NeuroCareer
chmod +x run.sh        # один раз
./run.sh
```

### Если автозапускалка не сработала (любая ОС)

Ручной аналог из терминала в папке проекта:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
python -m streamlit run app.py
```

## Что делать в приложении

После запуска в браузере откроется веб-интерфейс с боковой панелью
управления и четырьмя вкладками.

**Сценарий быстрого ознакомления (5 минут):**

1. В сайдбаре оставьте режим *«Пилотный респондент»* и выберите
   `R-04` (профиль INTP-A, кластер mobilized —
   хороший пример).
2. Вкладка **«Профиль»** — увидите радар интеллектов Гарднера и
   прогнозируемые роли Neiry.
3. Вкладка **«Рекомендации»** — топ-8 профессий с разбивкой скора по
   четырём компонентам. Поэкспериментируйте со слайдерами весов в
   сайдбаре: рекомендации перестроятся в реальном времени.
4. Вкладка **«Детальный разбор»** — выберите любую профессию из топа,
   увидите матчинг по интеллектам, MBTI, ролям и автоматическое
   текстовое объяснение.
5. Вкладка **«Отчёт»** — кнопка «Сформировать PDF» сгенерирует
   персональный документ A4 (до 30 секунд). Скачается на ваш диск.

**Сценарий «другой респондент»:**
   В сайдбаре переключите режим источника на *«Загрузить Neiry-выгрузку»*
   и подгрузите свой `.xlsx` с тем же набором колонок, что и в
   `data/raw/pilot_47x65_anon.csv`. Структура колонок — в `reports/data_dictionary.md`.

## Что можно проверить независимо (без запуска UI)

Все ключевые числа в диссертации воспроизводятся скриптами в `scripts/`.
Если хотите перепроверить какое-либо число вручную:

```bash
.venv\Scripts\activate    # активировать среду
pip install -r requirements-dev.txt  # один раз: добавить шаповый/обучательный набор

# Воспроизвести НИРМ-кластеризацию (silhouette должен быть 0.240, размеры [30, 8, 9])
python scripts\02_reproduce_nirm_clustering.py

# Перегенерировать синтетику с теми же параметрами
python scripts\03_generate_synthetic.py

# Сравнить real vs synth (35/38 KS-тестов проходят)
python scripts\04_validate_synthetic.py

# Переобучить модели предсказания ролей и пересчитать метрики
python scripts\05_train_role_models.py
```

## LLM-объяснения (опционально)

В архиве объяснения работают в **шаблонном режиме** — детерминированный
текст без LLM. Этого достаточно для оценки логики системы.

Если хотите увидеть генерацию реальной нейросетью, установите Ollama по
инструкции в `OLLAMA_SETUP.md` (один раз, ~15 минут). После этого
приложение само переключится на LLM-объяснитель — никаких изменений в
коде не требуется. Бэкенд индикатор в сайдбаре покажет, какой режим
активен.
